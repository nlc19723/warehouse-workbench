🗂 0 存量抽查清单

开局时被判定为「全 0 存量」而剔除的编码。它们不占序号、不进常规分派，但不会被丢弃——管理员可单独勾选指派抽查，专门用来发现「有实物、无账面」的盘盈。

📌 结论

  • 甲（现状）序号稳定，但清单臃肿——盘点人对着大量 0 存量行白忙。你的主诉就是它。
  • 乙（实时剔除 0 存量）清单干净了，但序号池每天重算 → 管理员认知与系统不一致，产生不可预测的隐性遗漏（甚至可能重复盘）。这是最危险的。
  • 丙（批次基线快照）开局冻结一份有效编码名册，序号全程稳定 + 清单干净。未覆盖项是明示的、可控的（开局时为 0 存量），且已列在抽查清单里。
  • 📎 顺带纠正一个直觉：「存量被清零」的行不算白盘——账上还有数、实物出库没了，这正是一次合法的盘亏记录，必须留给盘点人现场核实。真正浪费的是从未有货的 0 存量行（图中划线红块）。
